## Experiment 1: Rare Earth Element Finder

This beginner Python experiment detects rare-earth element symbols in chemistry text.

Example input:

La2(MoO4)3 and Eu doped compounds were investigated using powder XRD and UV luminescence.

Example output:

- La
- Eu
